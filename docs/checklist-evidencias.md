# Checklist de evidências do Trabalho Final

## Desenvolvimento

- [ ] Repositório público no GitHub.
- [ ] Site funcionando no GitHub Pages.
- [ ] Histórico de commits coerente.
- [ ] Capturas do guia em smartphone Android.
- [ ] Link testado em janela anônima.

## Aplicação presencial

- [ ] Foto do aluno apresentando o projeto.
- [ ] Foto geral da oficina com os quatro participantes.
- [ ] Foto do guia aberto em um smartphone.
- [ ] Foto do aluno auxiliando um participante.
- [ ] Foto ou vídeo de uma atividade prática.
- [ ] Autorizações de imagem e voz assinadas.
- [ ] Vídeo de até cinco minutos, com apresentação do aluno no início.

## Resultados

- [ ] Ficha de avaliação antes e depois preenchida.
- [ ] Feedback dos quatro participantes.
- [ ] Relato de dificuldades reais.
- [ ] Pelo menos três aprendizados para as considerações finais.
- [ ] Links públicos e testados antes da postagem.
